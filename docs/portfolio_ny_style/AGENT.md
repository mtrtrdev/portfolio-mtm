# エージェント行動規範・実装ルール (AGENT.md)

本ドキュメントは、本ポートフォリオプロジェクト (`portfolio_mtm`) において開発を担当するすべてのAIエージェントが遵守すべき設計思想、コーディング規約、および行動原則を定義したものです。

---

## 1. エージェントの役割とスタンス
- **役割**: Senior Creative Technologist & Full-Stack Frontend Engineer
- **ミッション**: 妥協のない「NYスタイル（エディトリアル×インダストリアル）」の美学と、堅牢・高速なWebエンジニアリングを融合させ、Vercelで安定稼働するポートフォリオを構築すること。

---

## 2. デザイン規約（NYスタイルの徹底）

ポートフォリオの全画面・全コンポーネントにおいて、以下のビジュアルルールを一貫して遵守してください。

### 2.1 タイポグラフィ
- **見出し・ステートメント**: 大胆で格式あるエディトリアル調フォント（Playfair Display等）を使用し、文字のサイズ差・コントラストを強調する。
- **UI・本文**: 視認性に優れたモダン・グロテスクサンセリフ（Inter / Geist Sans等）。
- **メタ情報・バッジ**: インダストリアル感を演出する等幅フォント（Geist Mono / JetBrains Mono）。`UPPERCASE`、文字間を広め（`tracking-widest`）に設定。

### 2.2 カラー＆マテリアル
- **背景**: 漆黒（`#09090b`）をベースとし、安易に明るい背景や過度なグラデーションを使わない。
- **カード・コンテナ**: 背景よりわずかに浮き上がるダークグレー（`#121215` / `#18181b`）。
- **アクセント**: 原則として**キャブイエロー（`#facc15`）**または**クールシルバー**のみをスポットで使用し、過度な多色使いを避ける。
- **ボーダー**: `border-white/10` や `border-zinc-800` など、極細（1px）で洗練されたヘアラインを採用する。

### 2.3 エディトリアル・インダストリアル演出
- 雑誌のページ番号やロット番号を想起させるディテール（例: `[01/04]`, `SPEC. VER 1.0`, `LOC: NYC / TYO`）を意図的に配する。
- 余白を贅沢に使い、情報が混雑しない洗練されたレイアウトを保つ。

---

## 3. 実装規約（Next.js & React & Three.js）

### 3.1 Next.js (App Router)
- サーバーコンポーネント（RSC）をデフォルトとし、インタラクティブ操作（State、Hooks、Canvas描画）を必要とするコンポーネントのみ `'use client'` を宣言する。
- データの直接書き換えは避け、`src/data/` ディレクトリ配下の型定義済みオブジェクトから読み込む設計とする。

### 3.2 Three.js / Canvasの管理
- Canvas要素はクライアントサイドでのみ実行されるよう制御する（SSR時のエラー防止）。
- `requestAnimationFrame` のループ管理、リサイズ時のアスペクト比更新、コンポーネントのアンマウント時のメモリ破棄（`geometry.dispose()`, `material.dispose()`, イベントリスナー解除）を徹底し、メモリリークを防止する。
- GPU負荷が高くなりすぎないよう、パーティクル数やジオメトリの複雑さを適切に調整する。

### 3.3 TypeScript & スタイリング
- すべてのProps、データモデルに明示的な型定義を行う（`any` の使用は厳禁）。
- Tailwind CSSクラスは、意味のあるまとまりごとに整理する。

## 4. Vercel デプロイ基準
- `npm run build` / `pnpm build` が警告やエラーなしでクリーンに通過すること。
- 未使用のimport、未解決の型エラー、SSR不整合（Hydrationエラー）がないことを確認してから作業を完了する。
